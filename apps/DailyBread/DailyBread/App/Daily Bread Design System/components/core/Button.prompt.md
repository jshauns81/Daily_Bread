One-line: `gold` = Approve, and nothing else may be gold.

```jsx
<Button variant="gold" size="sm" icon="hand.thumbsup">Approve</Button>
<Button variant="capsuleHelp" icon="questionmark.circle" block>Help</Button>
<Button variant="capsuleAccent" icon="checkmark.circle.fill" block>Done</Button>
<Button variant="bordered">Cancel</Button>
```

Minimum height is 44px (32 for `size="sm"` inline row actions). Disabled greys the
background rather than hiding the control.
