One-line: an icon, by its SF Symbol name — mapped to Lucide because SF Symbols can't ship to the web.

```jsx
<Icon name="checkmark.circle.fill" size={22} color="var(--ds-accent)" />
<Icon name="lock.fill" size={11} color="var(--ds-label-3)" />
```

Size it to the text beside it (11 caption2 · 12 caption · 15 subheadline · 17 body · 22 title2).
Requires the Lucide CDN script before the bundle. Flag the substitution in any handoff.
