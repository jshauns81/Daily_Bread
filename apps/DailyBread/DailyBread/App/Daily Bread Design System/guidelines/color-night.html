Night — decided: B, dusk slate

DrivingLogView.swift:147 hardcodes Color.indigo for night driving — the only unowned hue in the app. Whatever replaces it becomes an invariant, so it has to stay legible next to two blue theme accents (Sky, Harbor) and next to rarity‑epic, which is already violet.

A · Indigo

#4C5FD7 / #7B8AF0 · hue 232°
Closest to the Color.indigo it replaces, so nothing looks like it changed. But it sits between Sky's blue and epic's violet, and at small sizes it can read as either.

✅ Decided: B — dusk slate. #5560A8 light / #8D97D8 dark, live as --ds-night. Night is a fact about a drive, not a reward or a brand colour — it should be the quietest hue in the app, and being desaturated is what guarantees it never competes with an accent or a rarity. A and C both fight something.
