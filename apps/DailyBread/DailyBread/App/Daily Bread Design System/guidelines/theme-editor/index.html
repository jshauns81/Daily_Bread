Theme editor

Both modes, both platforms, live. Type in the YAML and the preview follows. Tap a gutter swatch to open a colour picker. The Smart quotes button reproduces the one bug that will otherwise cost you an evening.

Harbor is active, so the template starts from Harbor.
What to look at. The gutter is where the idea earns its keep — every hex line gets a tappable swatch, so you rarely type a hex by hand and the typo surface mostly disappears. Lint runs as you type, not on save, and Save stays disabled with the reason visible. Switching Simple ⇄ YAML is lossless: both edit the same model.
