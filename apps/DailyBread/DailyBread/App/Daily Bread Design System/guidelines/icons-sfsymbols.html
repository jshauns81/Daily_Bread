Phosphor is the chosen set — top row, via PhosphorSwift, behind a single DBIcon wrapper. Duotone for domain nouns, regular for chrome, fill for selected tabs.
The names under each group are the SF Symbols the app uses today, lifted from systemImage: in the Swift source — each column is that symbol's replacement. SF Symbols itself can't be shown here (Apple's licence forbids redistributing the glyphs) and it now survives only where iOS draws its own chrome: nav-bar backs, share sheets, context menus, swipe defaults. No override exists for those, so the seam is unavoidable and not worth fighting.
Iconoir and Remix are kept for reference; a dashed slot means that set has no such glyph. Lucide is the stand-in still used in these HTML kits — note how much colder it reads. Full comparison: Icon set candidates.
