App icon — five directions

Every one is shown at 29pt as well as 1024 — including the one you have now, at the top, so the comparison is direct. 29pt is the size that kills icons.

These are directions, not finished art — geometry I can build in CSS so you can judge the idea. Whichever you pick should be redrawn properly in a vector tool before it ships.

What's wrong with the current one

Current · shipping todayThe baseline

Judge the claims below against the ladder, not against my description of it.

Three problems, in order of severity. ① The grid is too fine — by 40pt the cells are sub-pixel and it reads as noise. ② The dark teal ground matches no shipping theme, including Sunroom, the default. ③ A single gold cell in a field of grey is a "one thing among many" idea, which is a completion metaphor — but the app's emotional centre is warmth and accumulation, not a lone highlight. The rainbow year fixes ③ for free, since the accumulated colour is the story.

The directions

A · Rainbow yearMy pick

A coarse 4×4 of the year's own hues, brightness varying like real days. It's the app's signature view reduced to sixteen cells — nobody else's icon looks like this, and it means the thing on the home screen is literally the thing inside.

Coarse is deliberate: 4×4 survives 29pt where 7×7 doesn't. It also gets better as it shrinks, blurring into a warm rainbow smear rather than falling apart.

B · The arcStrongest at small sizes

One rainbow sweep on cream. The same idea as A with all the detail removed — a year as a single gesture. This is the most legible option at every size and the most likely to still look right in five years.

The cost is that it's more abstract: it says "warm" and "spectrum", not "chores" or "family". Whether that matters for an app only five people will ever install is a fair question.

C · One gold cellMost native

Cream ground, a single rounded gold square. Maximum reduction, and it leans on the system's one true invariant — gold means money. Reads instantly at any size and sits comfortably beside Apple's own icons.

It is also the least distinctive of the five. A gold rounded square is a shape several apps already own.

D · The ringTies to the interaction

The check ring, mid-completion, in gold on the Sunroom ground. It depicts the single action the whole app is built around, and the gold flash on an earning chore is already the nicest moment in the product.

Risk: progress rings are extremely common on iOS, and a partial ring reads as "activity" or "storage" to anyone who doesn't know the app.

E · WordmarkWeakest

"db" set in SF Pro Rounded on gold. Included because it's the honest baseline — you have no logo, and a clean wordmark beats a mediocre picture.

But it's the one direction that says nothing about the product, and two lowercase letters at 29pt is a lot of nothing. I'd only take this if none of the others land.

On a home screen

This is the test that matters. Squint. The current icon is first, so the comparison is direct. A and B still read; C holds but could be any app; D reads as a progress indicator; E disappears. If you want my one-line answer: A, redrawn properly, with B as the fallback if it doesn't survive a real icon designer.

If you pick A

Three things to get right when it's redrawn:

① Don't use the literal day-1-to-365 hue ramp. A true spectrum has a muddy olive band around 70–90°. Hand-pick sixteen hues that stay warm and skip the mud.

② Vary brightness, not just hue. Uniform cells read as a colour-picker swatch. Uneven ones read as lived-in — which is the point.

③ Ground it in Sunroom's cream, not white and not dark. The icon should look like the default theme, since that's what most people will open into.
