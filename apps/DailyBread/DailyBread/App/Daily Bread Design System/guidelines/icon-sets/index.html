Icon set candidates

The same fourteen Daily Bread nouns rendered in every set that's a real option, at the size they'd actually appear. Switch themes — an icon set has to survive all six.

SF Symbols — what you have now

It can't be shown on this page, and that's the honest headline. SF Symbols is a system font licensed for Apple platforms only — there is no web build, no CDN, no npm package. Everything below is what I can put in front of you; the incumbent has to be judged from the app itself.

What it gives you that nothing else does: optical alignment with SF text at every weight, automatic Dynamic Type scaling, .symbolEffect animations (bounce, pulse, variableColor, replace), hierarchical and palette rendering modes, and ~6,900 glyphs maintained by the platform vendor. The check-button transition in spec §1.1 is built on .symbolEffect.

Anything you swap in loses .symbolEffect, Dynamic Type coupling, and optical alignment with SF text. That's the real price, and it's why my recommendation is a hybrid rather than a replacement.

Phosphor — my recommendation

Phosphor~9,000 glyphs · 6 weights · MIT · PhosphorSwift SPM package Pick
Duotonethe reason it wins
Fillfor selected tab states
Why this one. Rounded terminals and a generous counter — warm without being childish, which is the exact register Daily Bread needs and the thing most icon sets get wrong in one direction or the other. Six weights means the parent surfaces can run lighter than the kid ones from a single family. And Duotone gives a second layer you can colour independently: primary at label colour, secondary at the theme accent or gold. No other free set offers that, and it maps directly onto your themeing ambition.

Caveat, stated plainly: in the web icon-font above, duotone's second layer is just reduced-opacity currentColor — you only get true independent layer colouring in SwiftUI/SVG via PhosphorSwift. So the two-tone advantage is real in the app but not fully visible on this page.

Iconoir — the strongest single-set alternative

Iconoir~1,600 glyphs · one weight · MIT · SVG, no official Swift package
Handsome, consistently drawn, and warmer than Lucide. Choose this if you'd rather have one uniform set everywhere and no hybrid to reason about. Two real costs: only one weight (no lighter parent / heavier kid distinction), and no Swift package — you'd vendor SVGs into the asset catalogue yourself, which also means no Dynamic Type scaling for free.

Remix Icon — if tab states matter most

Remix Icon~3,000 glyphs · paired line + fill · Apache 2.0
Fillevery glyph has a matching filled twin
The line/fill pairing is genuinely well done and drops straight into a tab bar's unselected/selected states. But the drawing is squarer and more utilitarian than Phosphor or Iconoir — closer to a dashboard than to a family app.

What I'd actually do

Hybrid. Keep SF Symbols for system-adjacent affordances — chevrons, ellipsis, xmark, share, back — where they're invisible-by-design and where you need .symbolEffect. Add Phosphor Duotone for Daily Bread's own nouns: chore types, money, car, trophy, goals, badges.

The line is easy to hold: if the icon is part of iOS's furniture, SF Symbols. If it's part of your product's vocabulary, Phosphor. The furniture should disappear; the vocabulary should have character.

And because icons.set is in the YAML theme schema (spec §3.2), this is reversible per theme — you can ship the hybrid, and still let your son's custom theme swap the whole domain set. Which makes this a low-stakes decision, not a one-way door.
